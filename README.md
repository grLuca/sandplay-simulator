# 心理沙盒

一个本地运行的心理沙盘互动体验。用户可以在浏览器中选择、拖拽和摆放沙具，记录作品标题、当前心情、关键词与自述文本，并主动导出 PNG 截图、JSON 布局或复制给分析 Agent 的提交文本。

> 本项目用于自我表达、情绪觉察和心理教育场景，不提供心理诊断、心理治疗、医疗建议或危机干预。

![心理沙盒界面预览](./sandplay-wide-optimized.png)

## 项目特点

- 本地单页应用：不需要后端服务，不需要数据库。
- 虚拟沙盘创作：支持沙具分类筛选、搜索、点击添加和拖拽添加。
- 沙具编辑：支持移动、缩放、旋转、翻转、复制、删除、置顶和置底。
- 作品记录：支持填写标题、心情、关键词、自述文本和一句观察。
- 主动导出：支持保存沙盘 PNG、导出 JSON、复制分析 Agent 文本。
- 隐私优先：页面不会自动上传截图、文本或布局数据。

## 快速开始

项目主体位于 `sandplay-interactive/`。

最简单的方式是直接用浏览器打开：

```text
sandplay-interactive/index.html
```

也可以启动一个本地静态服务器：

```bash
cd sandplay-interactive
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 使用方法

1. 打开页面后阅读欢迎弹窗中的玩法说明和安全边界。
2. 在左侧沙具库中选择分类，或通过搜索找到需要的沙具。
3. 点击沙具或将沙具拖拽到中央沙盘。
4. 选中沙盘中的物件后，可在右侧调整名称、大小、旋转、翻转和层级。
5. 在右侧填写作品标题、当前心情、关键词和自述文本。
6. 使用顶部工具栏保存 PNG、导出 JSON，或复制给分析 Agent 的文本。

## 导出内容

### PNG 截图

点击 `保存 PNG` 后会下载沙盘区域截图，文件名格式如下：

```text
sandplay-YYYYMMDD-HHMMSS.png
```

截图只包含中央沙盘，不包含侧栏、工具栏或作品文字。

### JSON 布局

点击 `导出 JSON` 后会导出当前作品文本与沙盘对象布局，适合后续存档、调试或二次处理。

### 分析 Agent 文本

点击 `复制给分析 Agent` 后会复制一段中文提交文本，包含作品信息、用户自述、引导观察、安全边界和布局摘要。用户需要自行决定是否提交给外部 Agent 或其他工具，网页不会自动发送。

## 开发与测试

安装依赖：

```bash
cd sandplay-interactive
npm install
```

运行 Playwright 测试：

```bash
npm test
```

当前应用没有构建步骤，核心功能由原生 HTML、CSS 和 JavaScript 实现。

## 安全与隐私

- 本工具不是心理诊断、心理治疗或医疗建议工具。
- 任何后续分析只能作为自我反思和心理教育参考。
- 如果用户出现自伤、伤人、严重痛苦或危机风险，应联系当地紧急服务、危机热线、专业心理工作者或身边可信任的人。
- 图片、文字和布局数据默认只在本地浏览器中处理。
- 用户需要主动下载截图、导出 JSON 或复制文本。

## 已知限制

- 刷新页面会丢失当前作品，当前版本没有本地历史记录。
- 移动端支持基础操作，但复杂排布更适合平板或桌面浏览器。
- 前端目前内置一组可用沙具，完整资源包和动态加载能力仍可继续扩展。
- 撤销和重做只保存在当前页面内存中。
