# QA Checklist

## 运行环境

- [ ] 直接打开 `index.html`，页面能显示完整 UI。
- [ ] 如浏览器对本地文件限制较多，可用 `python -m http.server 8000` 启动静态服务器验证。
- [ ] 控制台无明显严重错误。

## 欢迎页与安全边界

- [ ] 首次进入显示“心理沙盘互动体验”欢迎/引导模态框。
- [ ] 文案说明这里不是测试，没有标准答案。
- [ ] 文案说明后续分析仅用于自我反思，不构成心理诊断、心理治疗或医疗建议。
- [ ] “查看安全说明”可展开危机支持和本地隐私说明。
- [ ] 必须勾选理解声明后才能开始体验。

## 沙具库

- [ ] 左侧显示至少 10 个可用沙具。
- [ ] 分类筛选可用。
- [ ] 搜索可按名称、类别或 id 匹配沙具。
- [ ] 点击沙具可添加到沙盘中心。
- [ ] 拖拽沙具到沙盘可在落点附近创建对象。

## 沙盘交互

- [ ] 沙盘显示柔和沙色背景、边界框和轻微纹理。
- [ ] 点击对象可选中。
- [ ] 点击空白处可取消选中。
- [ ] 选中对象可拖拽移动。
- [ ] 键盘方向键可微调选中对象位置。
- [ ] Delete 或 Backspace 可删除选中对象。
- [ ] 对象显示选中状态。

## 对象属性

- [ ] 右侧对象属性面板显示名称。
- [ ] 修改名称可反映到沙盘对象和对象列表。
- [ ] 大小滑杆可缩放对象。
- [ ] 旋转滑杆可旋转对象。
- [ ] 水平翻转开关可翻转对象。
- [ ] 复制按钮可复制对象。
- [ ] 删除按钮可删除对象。
- [ ] 置顶按钮可提高层级。
- [ ] 置底按钮可降低层级。

## 作品信息

- [ ] 可填写作品标题。
- [ ] 可选择当前心情：平静、好奇、紧张、疲惫、开心、迷茫、其他。
- [ ] 可填写逗号分隔关键词。
- [ ] 可填写自述文本。
- [ ] 没有方向时，可使用轻量引导提示和“一句观察”记录。
- [ ] 不收集真实姓名、联系方式、年龄、病史等敏感信息。

## 撤销、重做、重置

- [ ] 添加对象后可撤销。
- [ ] 撤销后可重做。
- [ ] 移动、缩放、旋转、翻转、复制、删除、层级调整进入撤销历史。
- [ ] 重置有确认弹窗。
- [ ] 重置后可通过撤销恢复。

## 截图与导出

- [ ] 点击保存 PNG 可下载沙盘区域截图。
- [ ] PNG 文件名格式为 `sandplay-YYYYMMDD-HHMMSS.png`。
- [ ] 点击导出 JSON 可下载会话 JSON。
- [ ] JSON 文件名格式为 `sandplay-session-YYYYMMDD-HHMMSS.json`。
- [ ] JSON 包含 `version`、`createdAt`、`title`、`mood`、`keywords`、`selfNarrative`、`objects`、`disclaimer`。
- [ ] JSON 包含可选 `guidance.prompt` 和 `guidance.note`。
- [ ] `objects` 包含 id、type、name、category、x、y、width、height、rotation、zIndex、flipped。

## 分析 Agent 提交文本

- [ ] 点击复制按钮可复制中文提交文本。
- [ ] 文本包含截图提交说明。
- [ ] 文本包含作品标题、当前心情、关键词、自述。
- [ ] 文本包含引导提示和用户的一句观察。
- [ ] 文本包含非诊断、非治疗、非医疗建议的安全边界。
- [ ] 文本不会生成诊断、人格判定或确定性心理标签。

## 移动端和窄屏

- [ ] 窄屏下工具栏可换行。
- [ ] 沙具库、沙盘、属性面板垂直排列。
- [ ] 触控拖拽可基本移动对象。
- [ ] 文本不明显溢出或遮挡关键控件。

## 隐私与安全回归

- [ ] 前端没有自动上传截图、文本或布局数据。
- [ ] 没有接入远程分析 API。
- [ ] UI 不输出“你有抑郁症”“人格问题”“创伤表现”等确定性心理标签。
- [ ] 危机内容只提示联系当地紧急服务、危机热线、专业人员或可信任的人。
