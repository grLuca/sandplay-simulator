# 安全与隐私说明

本文档说明“心理沙盘互动体验”的使用边界、安全提醒与隐私处理方式。

## 使用边界

“心理沙盘互动体验”不是心理诊断工具、心理治疗服务、医疗服务或医疗建议来源。它不能替代心理咨询师、精神科医生、医生或其他合格专业人员的评估与支持。

系统中出现的任何观察、提示或分析，都只能用于自我反思、情绪整理和表达探索，不应被理解为确定性的心理结论、诊断结果、治疗方案或风险评估。

前端 UI 不生成确定性心理标签，不应给用户贴上“抑郁”“创伤”“人格类型”“风险等级”等确定性心理或医学标签。

## 危机与紧急情况

如果用户正在经历自伤、伤人、严重痛苦、失控感、现实危机，或认为自己/他人可能处于危险中，应立即联系当地紧急服务、危机热线、医疗机构，或寻求可信赖的专业支持。

本体验不适合处理紧急心理危机，也不能提供实时危机干预。

## 隐私与数据流

用户在前端创建的沙盘图片、文字记录和互动内容，默认只保存在本地浏览器中，不会自动上传到服务器或第三方服务。

前端不会自动发送图片、文本、截图、分析请求或任何服务请求。除非用户明确执行导出、下载、复制或提交等主动操作，否则系统不应把用户内容发送到外部。

用户可以主动下载沙盘截图，并自行决定是否提交给分析 Agent。分析 Agent 只应处理用户主动提供的材料。

## 用户控制

用户应始终知道哪些内容留在本地、哪些内容被自己导出，以及哪些内容被自己提交给分析 Agent。

在提交图片或文本前，用户应有机会检查内容，并可以选择不提交、删除、重新编辑或仅保留在本地。

## 分析 Agent 的限制

分析 Agent 的输出应保持非诊断、非治疗、非医学建议的表达方式。它可以帮助用户观察画面元素、描述可能的感受线索、提出开放式反思问题，但不能给出确定性心理判断。

分析 Agent 在发现自伤、伤人、严重痛苦或危机风险相关内容时，应提醒用户联系当地紧急服务或专业支持，而不是继续进行普通分析。

## 开发与设计要求

- 不自动上传用户图片或文本。
- 不在前端自动调用任何分析服务。
- 不生成确定性心理标签。
- 不把反思性分析包装成诊断、治疗或医疗建议。
- 明确区分“本地保存”“用户下载”“用户主动提交给分析 Agent”三个动作。
- 在涉及危机风险时，优先提示用户联系当地紧急服务或专业支持。
