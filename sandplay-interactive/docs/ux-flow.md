# 心理沙盘互动体验用户流程

## 流程总览

完整用户流程分为 1-8 个阶段：

1. 进入体验
2. 阅读边界说明
3. 选择体验模式
4. 创建沙盘
5. 自由摆放与调整
6. 完成前自我检查
7. 主动选择是否提交
8. 查看非诊断性回顾或结束体验

## 1. 进入体验

用户从活动入口、网页入口、学校活动二维码、团体主持人链接或个人收藏入口进入产品。

页面目标：

- 让用户快速理解这是一次沙盘创作体验。
- 营造温和、安全、低压力的开始氛围。
- 不使用测评、诊断、检测、判断等高压力表达。

关键文案：

- “欢迎来到心理沙盘互动体验。”
- “你可以在这里自由选择沙具，摆出一个属于此刻的场景。”
- “没有标准答案，也没有好坏评分。”

## 2. 阅读边界说明

用户开始前看到简短边界说明。

必须说明：

- 本体验非诊断。
- 本体验非治疗。
- 本体验非危机干预。
- 沙盘摆放不会被解释为确定性心理结论。
- 后续如需回顾分析，必须由用户主动提交。

交互要求：

- 提供“我知道了，开始体验”按钮。
- 提供“暂不开始”或返回入口。
- 不用强迫式、恐吓式文案。

## 3. 选择体验模式

用户根据场景选择模式。

模式建议：

- 自由体验：适合普通体验用户。
- 学校活动：适合学校心理健康活动。
- 团体带领：适合团体活动主持人组织现场体验。
- 自我探索：适合个人自我探索者进行较安静、较完整的创作。

交互要求：

- 模式只影响引导语、时间提示和分享方式。
- 模式不改变心理解释逻辑。
- 不因用户选择某个模式而输出标签化判断。

## 4. 创建沙盘

用户进入空白沙盘画布。

页面组成：

- 中央沙盘区域。
- 沙具分类栏。
- 常用操作区：撤销、重做、清空、保存草稿、结束。
- 温和提示区，可展示简短开放式引导。

体验原则：

- 默认不自动分析用户操作。
- 不在用户摆放时弹出心理解释。
- 不用颜色、警告或分数暗示作品状态。

## 5. 自由摆放与调整

用户从沙具库中选择元素，放入沙盘并自由调整。

支持操作：

- 添加沙具。
- 移动沙具。
- 旋转沙具。
- 缩放沙具。
- 删除沙具。
- 调整层级或位置。
- 清空重来。

引导方式：

- 使用开放问题，而不是标准答案。
- 示例：“你可以从最想放入的一个元素开始。”
- 示例：“如果愿意，可以留意哪些元素被放得更近或更远。”

禁止行为：

- 不提示“你应该放什么”。
- 不提示“这样摆更健康”。
- 不根据操作实时显示心理标签。
- 不把某个沙具或位置解释为固定心理意义。

## 6. 完成前自我检查

当用户点击完成或准备离开时，进入完成前检查。

页面目标：

- 帮助用户确认作品是否已经表达完毕。
- 给用户保留继续编辑、不提交、直接结束的选择。

可提供的问题：

- “这个场景现在对你来说完整吗？”
- “有没有哪个部分你还想移动、添加或移除？”
- “如果只给这个场景起一个名字，你会想到什么？”

交互选项：

- 继续编辑。
- 仅结束体验。
- 进入提交确认。

## 7. 主动选择是否提交

这是分析前的必经步骤。系统不得跳过此步骤自动生成分析。

确认页必须说明：

- 提交后将生成非诊断性回顾。
- 回顾只基于作品中可见元素和用户可选输入。
- 回顾不是心理诊断、治疗建议或危机干预。
- 用户可以取消提交并继续编辑或直接结束。

交互选项：

- “提交并查看回顾。”
- “返回继续编辑。”
- “不提交，结束体验。”

关键要求：

- 默认不勾选同意。
- 不用诱导性按钮文案。
- 不把“不提交”设计成弱化、隐藏或羞辱性选项。

## 8. 查看非诊断性回顾或结束体验

如果用户提交，进入回顾页。如果用户不提交，则进入结束页。

### 提交后的回顾页

回顾结构建议：

- 边界提醒：再次说明内容不是诊断或治疗建议。
- 作品概览：客观描述沙具类别、空间关系和显著元素。
- 可能主题：以开放语言提出可能关注点。
- 自我提问：提供用户可自行思考的问题。
- 下一步选择：保存、导出、返回编辑、结束体验。

表达要求：

- 使用“可能”“也许”“可以观察”“你可以想一想”。
- 避免“说明”“代表”“证明”“检测出”等确定性词语。
- 不给出人格判断、病理判断或治疗建议。

### 不提交的结束页

结束页目标：

- 尊重用户选择。
- 不追问、不施压、不暗示用户错过了更重要的信息。

关键文案：

- “这次体验已结束。你的作品可以只属于你自己。”
- “你可以稍后再回来继续探索。”

## 学校与团体场景补充流程

主持人在活动前需要说明：

- 活动不是心理测评。
- 不要求公开作品。
- 分享必须自愿。
- 任何人都可以选择跳过、退出或只体验不提交。
- 不允许同伴对他人的作品做诊断式解读。

活动结束时建议：

- 让用户用自己的语言描述作品。
- 主持人只做开放式提问。
- 不对个体作品下结论。
- 不把作品用于排名、筛查、评价或处分依据。

## 异常与风险处理

当用户输入或作品标题中出现明显危机表达时：

- 不进入诊断或分析。
- 温和提示产品无法提供危机干预。
- 建议用户立即联系身边可信赖的人、当地紧急服务或专业危机援助资源。
- 在学校或团体场景中，提示联系现场负责的心理老师、活动负责人或监护支持人员。

## 全流程体验原则

- 温和。
- 不评判。
- 不暗示标准答案。
- 不把摆放解释为确定性心理结论。
- 分析前用户主动选择是否提交。
- 用户随时可以退出。
- 分享必须自愿。
