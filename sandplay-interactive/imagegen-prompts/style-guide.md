# Sandplay Asset ImageGen Style Guide

## Unified Base Style

Use this base prompt for every final asset:

> Create a single isolated sandplay miniature object for a digital therapeutic sandbox interface. 3/4 top-down view, soft hand-drawn healing illustration style, low-saturation warm colors, transparent background, centered object, no text, no watermark, no harsh shadows, suitable as a draggable object on a virtual sand tray.

## Output Rules

- Format: PNG with transparent background.
- Composition: one object only, centered, with a small amount of empty margin.
- Perspective: consistent 3/4 top-down view so objects can sit naturally on the virtual sand tray.
- Style: soft hand-drawn illustration, warm and low-saturation palette, gentle edges, subtle texture.
- Lighting: soft ambient light, no harsh shadows, no dramatic contrast.
- Safety tone: avoid horror, gore, medical framing, diagnostic symbols, or threatening expressions.
- Text: no letters, numbers, labels, signatures, or watermarks inside the image.
- Symbolic use: assets are open-ended sandplay objects. Do not encode a fixed psychological meaning into the image.

## Recommended Palette

- Warm neutrals: sand, clay, linen, muted stone.
- Nature accents: sage green, soft moss, muted blue-green.
- Warm accents: muted gold, terracotta, soft coral.
- Avoid highly saturated neon colors, black-heavy silhouettes, and clinical white-blue styling.

## Prompt Pattern

```text
Create a single isolated sandplay miniature object: [specific object description], 3/4 top-down view, soft hand-drawn healing illustration style, low-saturation warm colors, transparent background, centered object, no text, no watermark, no harsh shadows, suitable as a draggable object on a virtual sand tray.
```
